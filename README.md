FitnessApp is a web-based application designed to help users track and manage their fitness routines and goals. It provides an intuitive interface for logging workouts, monitoring progress, and staying motivated on the path to a healthier lifestyle. The live demo showcases the main features of the app, allowing users to experience its functionality firsthand.


## Features

- **Workout Logging:** Easily log workouts with details such as exercise type, duration, and intensity.
- **Progress Tracking:** Visualize your progress over time with charts and statistics.
- **Goal Setting:** Set fitness goals and track your achievements.
- **User Profiles:** Create and manage personal profiles to keep track of individual fitness journeys.
- **Responsive Design:** Enjoy a seamless experience on both desktop and mobile devices.

## Getting Started

To run the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/madalinagomei/fitnessApp.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd fitnessApp
   ```

3. **Open `index.html` in your browser:**
   ```bash
   open index.html
   ```

## Usage

Explore the application by navigating through the different sections:
- **Home:** View an overview of your fitness progress and recent activity.
- **Log Workout:** Add new workout entries with details about each exercise.
- **Progress:** View charts and stats that highlight your progress over time.
- **Profile:** Manage your personal information and fitness goals.
